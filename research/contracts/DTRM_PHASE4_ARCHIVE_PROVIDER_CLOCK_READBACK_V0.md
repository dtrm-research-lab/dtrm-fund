## Research question and non-permitted inferences

Can a second, separately acquired provider API readback corroborate that GitHub says a named archived ranking ZIP existed no later than `artifact.created_at`, for the **exact run and artifact identity pinned before the readback**? YES only for matched metadata observations. This does not establish original article or link creation time; source rights, FMP/Mongo first-seen clocks, absent links, a complete 60-day history, asset prices, decision eligibility, model outcome or causal economic improvement remain UNKNOWN/BLOCKED. Retention expiration is not proof original bytes survive and must be treated operationally, not scientifically.

## Closed immutable graph

1. **Input source:** caller-supplied bytes of `DTRM_PHASE4_21_ARCHIVED_RANKING_SOURCE_MANIFEST_V0.json`. Before processing provider responses, require exact Git blob SHA-1 identity above, 21 distinct run IDs, 21 distinct artifact IDs, 21 source rows, expected backend repository; reject missing/extra identities or changed manifest. No row may contain raw article/ticker/headline/source text, URL, financial outcome, credentials or price.
2. **Input readback:** caller-supplied JSON `GET /repos/tech-com-UA00001/theresistance-back/actions/runs/{run_id}/artifacts` body from each of the pinned 21 run IDs. Exactly 21 files named `{run_id}.json` in a private or operator-local directory, with no additional `.json` files. Enforce `total_count == len(artifacts)` to avoid silently accepting truncated pagination. Reject a missing/duplicate artifact ID or ambiguous identity; require `artifact.id`, `name=daily-ranking-{run_id}`, `workflow_run.id=run_id`, `created_at` exactly equal to pinned original UTC (strict canonical `YYYY-MM-DDTHH:MM:SSZ`), `expired` a proper boolean false, and a valid `expires_at` after the explicit recorded check time. No live network calls by verifier.
3. **Capture boundary:** an archive can witness a positive selected representation before cutoff `c` *only if* the independently matched provider `created_at < c`. Equality excludes the archive. The market `asOf` is not the capture clock; independent readback confirms source provider metadata agreement only, not an independently notarized timestamp.
4. **Output:** deterministic, sorted, aggregate-only readback assessment with counts, SHA/manifest identity, earliest provider-reported expiry, strict matching result and fail-closed noncounting statuses. Do not emit company IDs, article IDs, SHA of article text, URLs, raw provider JSON, credentials, prices or outcomes. Never encode positive source admission when any row fails. No output file should be created on failure.
5. **Test acceptance:** genuine single-source corpus needs the exact 21-source manifest and complete raw provider responses; wholly fictional synthetic unit tests cover exact match, swapped run/artifact, timestamp mismatch, missing/extra/truncated responses, corrupt JSON, ambiguous artifact, expired and cutoff equality. Synthetic tests must not assert a real 21/21 run has been replayed.
6. **Review gates:** preregistration commit must precede code, synthetic tests and report; scoped Ruff, mypy --strict, all regression tests and 157 inherited Phase III blob preservation. No merge before separate human review and approval.
